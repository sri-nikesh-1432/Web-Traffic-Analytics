WEB TRAFFIC ANALYTICS

OVERVIEW
This project focuses on analyzing website traffic data to decode user behavior. By tracking page views, session durations, and exit points, the analysis identifies exactly where users lose interest and suggests improvements to boost digital engagement.

OBJECTIVES
1. Measure total page views and average session duration across the platform.
2. Identify specific drop off points where users exit the website prematurely.
3. Map user journeys from the landing page to final conversion.
4. Provide data driven suggestions to improve the user experience.

ANALYSIS WORKFLOW
Phase 1: Traffic Simulation. Generating a dataset that mimics multi page user sessions and interaction times.
Phase 2: Metric Aggregation. Calculating total engagement time and frequency of visits per page.
Phase 3: Exit Rate Analysis. Determining the probability of a user leaving from each specific page.
Phase 4: Funnel Visualization. Creating charts to visualize the conversion funnel and identify bottlenecks.

KEY FINDINGS
1. The Home page typically sees the highest volume but also the highest immediate bounce rate.
2. Session duration increases significantly for users who reach the Pricing page.
3. Drop off points are most frequent at the Signup stage, indicating potential friction in the registration form.

TOOLS USED
Python
Pandas for data manipulation
Matplotlib and Seaborn for funnel visualization
Google Colab

HOW TO USE
Launch the notebook in Google Colab to run the traffic simulation. The resulting charts will highlight the specific pages that require optimization to improve overall retention.
